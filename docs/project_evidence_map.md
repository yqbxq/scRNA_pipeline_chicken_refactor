# Project Evidence Map

The project evidence chain uses ST09 SVG as a gene-level spatial evidence layer.

ST09 supports:

- communication: `svg_lr_support.tsv`
- regulation: `svg_regulation_support.tsv`
- enrichment/gene programs: `svg_gene_sets.tsv` and `svg_enrichment_handoff.tsv`
- trajectory and velocity in space: `svg_trajectory_support.tsv`
- exploratory question gates: `svg_question_gate_status.tsv`

ST09 does not prove directionality, causality, ligand-receptor activity, or pseudotime direction on its own. It annotates whether relevant genes have spatial expression patterns compatible with upstream hypotheses.
